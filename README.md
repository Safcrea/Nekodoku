# Nekodoku

Meowdoku is a cozy cat-themed logic puzzle where each board hides playful cats. Use clues from rows, columns, colored regions, and neighboring cells to mark impossible spaces, reveal the right cats, and solve each level before your hearts run out.

## Gameplay

- Find exactly one cat in every row.
- Find exactly one cat in every column.
- Find exactly one cat in every colored region.
- Cats cannot touch horizontally, vertically, or diagonally.
- Tap to mark impossible cells with crosses.
- Double-tap when you are sure a cat is hidden in a cell.
- Wrong guesses cost hearts.

## Project

This is a Unity mobile puzzle game project targeting portrait play on Android and iOS.

Current prototype features include:

- Runtime-generated puzzle UI
- Sample puzzle levels
- Locked starter cats
- Cross marking
- Cat reveal checks
- Three-heart mistake system
- Undo and restart controls
- Early tutorial guidance
